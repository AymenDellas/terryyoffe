# Project instructions

- This project is local-only at the user's request. Do not publish or synchronize source to a hosted Site unless the user explicitly asks to deploy.
- Run `npm run build`, `npm run check`, and `npm run dev` for the static implementation. The preview is `http://127.0.0.1:4173/`. Reuse its existing listener and leave it running for the local handoff.
- Preserve the approved copy, the eight full testimonials and their attributions, and the consultation configuration unless the user requests changes.
- Verify responsive changes on phones, tablets and desktop. Keep the trust trail pausable and preserve its reduced-motion fallback.
